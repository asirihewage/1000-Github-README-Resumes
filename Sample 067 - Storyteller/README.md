# Milan Stojanovic

I'm a QA Engineer living in Almaty, Kazakhstan.

## The beginning

My story started with a broken computer and a library book about
Python. I wrote my first program to make a turtle draw a square —
and I was hooked.

## The middle

Years later I've shipped everything from pomodoro-app to todo-rest-api, taught
myself Bun on nights and weekends, and learned that the best
code is the code your future self can read at 2 AM.

## The now

Today I spend my time building game-engine-demo and helping other developers
grow. I believe in boring technology, clear commit messages, and
good documentation.

## The next

Next stop: Cassandra at scale, a few long walks, and whatever the
internet surprises me with next.
