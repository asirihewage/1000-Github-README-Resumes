# Yan Wu

I'm a AR/VR Developer living in Prague, Czechia.

## The beginning

My story started with a broken computer and a library book about
MATLAB. I wrote my first program to make a turtle draw a square —
and I was hooked.

## The middle

Years later I've shipped everything from meeting-scheduler to ecommerce-store, taught
myself Node.js on nights and weekends, and learned that the best
code is the code your future self can read at 2 AM.

## The now

Today I spend my time building flowchart-tool and helping other developers
grow. I believe in boring technology, clear commit messages, and
good documentation.

## The next

Next stop: TensorFlow at scale, a few long walks, and whatever the
internet surprises me with next.
