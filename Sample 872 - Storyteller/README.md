# Noah Bergstrom

I'm a Software Engineer living in Copenhagen, Denmark.

## The beginning

My story started with a broken computer and a library book about
TypeScript. I wrote my first program to make a turtle draw a square —
and I was hooked.

## The middle

Years later I've shipped everything from neural-style to meeting-scheduler, taught
myself Svelte on nights and weekends, and learned that the best
code is the code your future self can read at 2 AM.

## The now

Today I spend my time building docker-helper and helping other developers
grow. I believe in boring technology, clear commit messages, and
good documentation.

## The next

Next stop: GIMP at scale, a few long walks, and whatever the
internet surprises me with next.
