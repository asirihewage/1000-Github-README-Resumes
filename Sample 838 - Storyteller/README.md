# Bella Kaur

I'm a Rust Developer living in Havana, Cuba.

## The beginning

My story started with a broken computer and a library book about
Mocha. I wrote my first program to make a turtle draw a square —
and I was hooked.

## The middle

Years later I've shipped everything from ecommerce-store to devtools-cli, taught
myself Dart on nights and weekends, and learned that the best
code is the code your future self can read at 2 AM.

## The now

Today I spend my time building notes-sync and helping other developers
grow. I believe in boring technology, clear commit messages, and
good documentation.

## The next

Next stop: Flask at scale, a few long walks, and whatever the
internet surprises me with next.
